# Competences

## SIG et cartographie

- Conception et administration de donnees SIG
- Cartographie thematique
- Webmapping
- Analyse geospatiale
- Acquisition et traitement d'images satellitaires
- Traitement de donnees LiDAR et raster

## Bases de donnees spatiales

- Modelisation de donnees geographiques
- Requetes SQL
- Gestion de donnees avec PostgreSQL
- Extensions spatiales avec PostGIS
- Structuration et documentation de bases cartographiques

## Developpement Web SIG

- Interfaces cartographiques interactives
- Visualisation de donnees geographiques
- Tableaux de bord cartographiques
- Integration de couches et services cartographiques
- Publication de donnees SIG pour consultation web
