# DIR Est - Nancy

## Stage Master 2

Contexte : Direction Interdepartementale des Routes Est.

## Mission principale

Developper des applications Web SIG, des tableaux de bord et des outils cartographiques pour faciliter la consultation des donnees par les agents du service.

## Activites realisees

- Conception d'outils de consultation cartographique.
- Valorisation de donnees liees au patrimoine routier.
- Preparation de tableaux de bord pour la consultation metier.
- Organisation et documentation de donnees geographiques.
- Appui a la diffusion de l'information geographique.

## Competences mobilisees

- Web SIG
- Webmapping
- Dashboards cartographiques
- Gestion de donnees spatiales
- Documentation technique
- Analyse des besoins utilisateurs

## Outils associes

- ArcGIS Enterprise
- ArcGIS Dashboards
- Experience Builder
- QGIS
- PostgreSQL/PostGIS
- HTML, CSS, JavaScript
