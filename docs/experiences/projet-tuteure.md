# Projet tuteure universitaire

## Theme

Le webmapping : definition, utilite et outils.

## Objectif

Presenter les principes du webmapping et illustrer son utilite avec des exemples concrets.

## Competences mobilisees

- Recherche documentaire
- Synthese technique
- Presentation d'outils Web SIG
- Cartographie interactive
- Travail en equipe et autonomie

## Prolongement possible sur GitHub

Cette page pourra accueillir :

- des notes de cours ;
- des exemples de cartes web ;
- des comparaisons d'outils ;
- des liens vers des projets Leaflet ou ArcGIS.
